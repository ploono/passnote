Safe by design, in detail

  • Stays on your computer. Notes are plain files in a folder on your machine. passnote itself sends them nowhere. Delivered notes reach Claude through your usual Claude Code connection.
  • Clearly labelled. Every note arrives marked as coming from another session, not from you.
  • Careful sessions stay careful. Notes between a session that asks before acting and one that doesn’t are held both ways and shown only to you.
  • Keeps secrets out. passnote refuses to post text that looks like an API key, token or private key.
See the numbers

Waking an idle session starts a whole new turn of two or three model calls before any work happens. passnote adds the note to a step the session is already taking.

Costs are in input-token-equivalents for an Opus-class session with about 60,000 tokens of context (cache reads count 0.1×, output 5×), measured from real session transcripts. A delivery costs its payload plus a ~20-token header twice when written, then a tenth of that on every later call.

Questions

Do I need to know how to code?

No. You install passnote by pasting two lines into Claude Code, then ask each session to join. After that, your sessions write and read the notes themselves. You see a short line whenever a note arrives, and you can ask Claude what it said.

Is it free?

Yes. passnote is free and open source under the MIT licence, with no paid tier. It runs on your own computer, so there’s no account and no server. Each note uses a little of your Claude usage, far less than waking a session.

Does it upload anything?

passnote itself sends nothing anywhere. Rooms are plain files on your computer, in ~/.local/state/passnote by default. A note reaches Claude the same way the rest of your session does, through your usual Claude Code connection.

Does it work in the Claude desktop app?

passnote works through Claude Code’s plugin hooks and is tested in Claude Code in the terminal, on macOS and Linux. Other ways of running Claude Code may work too, but they haven’t been tested yet, so the terminal is the safe choice for now.
